# Lily Support ミドルエンド会員サイト

復縁サポートのミドルエンド購入者向け会員サイトです。

## 現在の実装

- 購入者専用ダッシュボード
- 動画講義とワーク一覧
- 進捗率と次に取り組む内容
- ワーク回答フォーム
- 運営管理画面
- 受講者別の進捗・最終取組日・困りごと
- 要確認、停滞中、順調の状態表示
- 個人詳細と取り組み推移グラフ
- スマートフォン対応

現在は画面構成を確認するための見本データ版です。実運用前に、既存会員サイトのSupabase認証・データベースへ接続します。

## 開発

必要環境: Node.js 22.13.0以上

```bash
npm install
npm run dev
```

本番用ビルドの確認:

```bash
npm run build
```

## 主なファイル

- `app/page.tsx`: 受講者画面・管理画面
- `app/globals.css`: 全体デザイン・レスポンシブ対応
- `app/layout.tsx`: サイト情報

## 次の実装

1. Supabase認証との接続
2. 購入者ごとのコンテンツ割り当て
3. 動画講義データの登録
4. ワーク回答と回答履歴の保存
5. 管理画面への実データ反映
6. 運営者権限と受講者権限の分離

実データや秘密情報はリポジトリへ直接コミットせず、環境変数で管理します。
