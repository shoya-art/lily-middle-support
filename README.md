# Re Relation 個別サポート会員サイト

既存Re Relation会員サイトの配色・余白・カード表現をデザイン基準として、新しく設計した個別サポート用会員サイトです。

既存サイトの複製ではなく、以下の機能に絞っています。

- 購入者専用ログイン
- 個人別ホームと受講進捗
- 動画講義
- ワーク回答と保存
- 運営者用の進捗・困りごと確認画面

## ファイル

- `index.html`: ログイン
- `dashboard.html`: 購入者専用ホーム
- `lectures.html`: 動画講義・ワーク
- `answers.html`: 保存した自分の回答を振り返る画面
- `admin.html`: 運営管理画面
- `styles.css`: 共通デザイン
- `app.js`: アカウント別コンテンツ・保存・画面動作
- `ayano-content.js`: あやのさん用の30回・300問の質問テンプレート
- `account-tests.cjs`: ID別保存・振り返り・既存回答引き継ぎの検査
- `brand-hero.png`: ログイン背景

## ローカル確認

```bash
python3 -m http.server 3010
```

`http://localhost:3010/` を開きます。

既存の001・002はブラウザ内保存の簡易版です。DB同期やサーバー側認証は未実装です。
ID・パスワード・質問テンプレートは公開ソースに含まれるため、機密性のある本番運用には使えません。
受講者の回答はGitHubへ送信されず、ID別キーでその端末・ブラウザのlocalStorageに保存されます。
別端末との共有はなく、ブラウザのデータ削除で失われます。管理画面も同じブラウザの回答だけを表示します。
この分離は通常の画面操作での混在を防ぐもので、第三者のアクセスを防ぐ本式の認証ではありません。

### ID 003：暗号化した過去ワークの振り返り

003は上記の簡易パスワード方式から分離した、読み取り専用アーカイブです。
共通ログイン画面から、運営者が個別に渡すランダムな専用パスワードで `archive.html` を開きます。
32回分のワーク・過去回答273件・補足34タブを、2026-11-02の原文と照合しました。
動画ファイル・動画URLは追加せず、以前送付したリンクの利用と必要時の再送を案内します。

- `archives/003.json` はAES-256-GCM暗号文。PBKDF2-SHA256（600,000回）とランダムsalt/IVを使用。Web Crypto APIでブラウザ内復号します。
- 平文の回答、パスワード、元シートのスナップショット、ローカル動画パスは公開しません。暗号文そのものは公開URLから取得できます。
- パスワードは18バイトの乱数から生成した24文字。短い名前などへ変更しないでください。パスワードを知る人は閲覧できます。
- 復号鍵のみをsessionStorageへ置き、ページ移動・再読込に対応。回答本文は永続保存しません。ログアウトで鍵を削除。8時間後の再読込時には再ログインが必要です。
- サーバー側アカウント認証・アクセス監査・遠隔失効・新規回答の保存は提供しません。旧暗号文と旧パスワードを保有する相手から、過去の閲覧権を取り消すことはできません。
- 従来の管理画面は001/002用のままです。運営者が003の記録を見る場合も専用IDとパスワードを使います。
- 元回答は閲覧専用として固定し、未記入欄は未記入、元の質問文が空欄の5か所はその旨を表示します。視聴完了や回答の補作は行いません。
- 既存のGitHub Pagesだけで配信します。R2、Supabase、有料契約、追加課金設定は使用・変更していません。

`scripts/pack-archive.cjs` はリポジトリ外の移行データから暗号化する運営者用ツールです。
標準出力には認証情報も含むため、そのままファイル化してコミットしないでください。
公開するのは `envelope` のみです。元データと認証情報はリポジトリ外で安全に管理します。
更新時は再取得した原文を確認して、現在の認証情報を指定して暗号化し直します。

暗号化方式の参考: https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/deriveKey

あやのさんの取り込みは質問・ねらい・注意書きのみです。記入例と過去の本人回答は含みません。
第1回〜第27回のワーク・登録動画を「過去に取り組み済み」と表示します。第28回〜第30回は初期状態では未完了です。
ミサキさんの旧保存キーは、001でログインした際に専用キーへコピーし、原本も残します。

## コンテンツ追加ルール

- 初期状態は講義0件
- 1回分は「動画講義＋ワーク」のセット
- 最初のセットを第1回、次のセットを第2回として追加
- ミサキさんは `app.js` の `misakiSessions`、あやのさんは `ayano-content.js` の `ayanoSessions` に登録
- 動画URL未登録の場合はワークだけ表示。後から同じ回へ動画を追加できる

node --check app.js

node account-tests.cjs
node archive-tests.cjs
